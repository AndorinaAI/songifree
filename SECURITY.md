# Security Policy

## Supported Versions

We actively provide security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| `dev`   | :white_check_mark: |
| `0.1.x` | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The Songifree team takes security and user privacy seriously, especially given that this project interacts with third-party OAuth tokens, client credentials, and live stream chats.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues using one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Submit a report via the [Security Advisories page](https://github.com/AndorinaAI/songifree/security/advisories/new).
2. **Email:** Send details to [andorinacoding@gmail.com](mailto:andorinacoding@gmail.com) with the subject `[SECURITY] Songifree Vulnerability Report`.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Clear steps or a proof of concept (PoC) to reproduce the issue.
- Any known remediation or patch suggestions.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide regular updates on our progress in validating and resolving the issue.
- A patched release will be published before disclosing any details publicly.
