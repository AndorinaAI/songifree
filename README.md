## 📖 About

**Songifree** connects your **Spotify** playback to **Twitch**, **Kick**, and **TikTok** live streams, enabling chat viewers across platforms to interact with and control the music directly through chat commands.

---

## 🎮 Platforms

- 🎧 **Spotify**: Music playback and queue integration.
- 🟣 **Twitch**: Live chat interaction.
- 🟢 **Kick**: Live stream chat integration.
- ⚫ **TikTok**: TikTok Live chat integration.

## 🌿 Repository & Branching Workflow

This repository uses a two-branch workflow:

- **`main`**: Stable production release branch.
- **`dev`**: Active development branch. **All Pull Requests and feature branches must target `dev`**.

```bash
# Clone the repository
git clone https://github.com/AndorinaAI/songifree.git
cd songifree

# Switch to the dev branch for active work
git checkout dev
```
